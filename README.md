# BumbumFlix — Upsell 1 (TSL)

Página de upsell do funil BumbumFlix (Acompanhamento **Musa Elite**), oferta do expert Murilo.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `upsell 1 tsl.html` | Versão original da página de upsell. |
| `upsell 1 tsl v2.html` | Nova versão — abre com "antes e depois" (3 depoimentos placeholder), hook "corpo dos sonhos" emendando no bloco dos 10 anos, carrossel infinito de depoimentos em imagem e depoimentos em estilo WhatsApp. |
| `upsell 1 tsl_files/` | Assets compartilhados (CSS, imagens, scripts de pixel/checkout). |

## Como abrir

Abra qualquer um dos `.html` direto no navegador. Os dois apontam para a pasta `upsell 1 tsl_files/` por caminho relativo.

## Placeholders a substituir (v2)

- **3 fotos antes/depois** do topo → trocar cada `<div class="ba-placeholder">` pelo `<img>` real.
- **5 slides do carrossel** → trocar cada `<div class="testi-ph">` pelo `<img>` real (editar os **dois blocos** duplicados com as mesmas imagens, na mesma ordem — o loop depende disso).
